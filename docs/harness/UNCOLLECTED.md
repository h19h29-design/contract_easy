# UNCOLLECTED.md — 수집하지 못한 정보와 그 이유

최종 갱신: 2026-08-26 · 모든 항목은 "왜 못했는가"와 "풀리는 조건"을 함께 기록한다.
무단 우회(robots·로그인·파라미터 추측)는 절대 원칙 위반이므로 수단으로 사용하지 않는다.

---

## 1. 첨부파일 원문 전체 (pdf / hwp / hwpx / doc / xls / xlsx / zip / png / jpg …)

- **상태**: 미수집 — 파일은 전부 **메타데이터만** 보관(URL·파일명·확장자)
- **이유**: `contract.sen.go.kr/robots.txt`가 해당 확장자 다운로드를 명시적 Disallow
  (2026-08-25 실측: `Disallow: /*.pdf$` 等 14종). seeds의 `obey_robots: true`와
  절대 원칙(robots 우회 금지)에 따라 차단. 결정 기록 D-001.
- **보유한 것**: 첨부 링크 목록(`data/manifests/files.jsonl`, sources.attachments)
- **영향**: 첨부 내부의 서식 양식·상세 표·안내문이 지식베이스에 없음 → 검색·위키 누락
- **풀리는 조건**: 서울시교육청 담당부서의 사전 서면 확인 후 `CRAWL_ALLOW_ATTACHMENTS=true`
  명시 승인 시 즉시 수집 가능(다운로더·MIME 검증·격리 로직은 구현·테스트 완료)

## 2. FAQ 게시판의 개별 Q&A 글 (계약일반 / 물품 / 용역 / 공사 4개)

- **상태**: 개별 글 미수집(0건)
- **이유**: 4개 FAQ 목록 페이지의 글 링크가 **외부 도메인**(buseo.sen.go.kr BBS)으로 연결됨.
  허용 범위(domain: contract.sen.go.kr, path: /fus/)를 벗어나므로 별도 allowlist 없이는
  본문 수집 금지(실행 프롬프트 §2·blueprint 수집 제외).
- **보유한 것**: 각 FAQ 목록 페이지에 **인라인으로 포함된 본문 일부**(faq 청크 247개,
  카테고리 메타 포함) — 일부 질의는 여기서 충족됨
- **영향**: FAQ 전체 문항 검색 불가, faqCategory 필터의 커버리지 제한
- **풀리는 조건**: buseo.sen.go.kr BBS allowlist 추가(법무 확인 후 `02_CRAWL_SEEDS.yaml`
  follow_rules 확장) → 동일 크롤러로 즉시 수집 가능

## 3. 계약방법 '원클릭' 업종별 상세 표 (MI485~504 등 gb/gy 페이지군)

- **상태**: 미수집(빈 껍데기만 확인됨)
- **이유**: 해당 페이지들은 초기 HTML/A 렌더 어느 쪽에도 본문이 없고,
  콘텐츠를 `fncSubView(gb, gy, gm, step, sort, index)` AJAX로 조립함.
  유효 파라미터 조합은 UI 클릭 탐색으로만 확인 가능하며, **조합 추측은 금지**(추측 금지 원칙).
- **보유한 것**: 계약방법 핵심 표는 **사전체크리스트(용역/공사) 정적 페이지**에서 이미 확보함
  → 구조화 규칙 초안 3건(수의계약 2000만~1억 / 입찰 <1억 / 입찰 1억~2.3억) + 문장 후보 60건(draft)
- **영향**: 업종별(청소용역, 전세버스 등 20여 종) 세부 계약방법 표 누락
- **풀리는 조건**: Playwright UI-walk(탭 클릭 → XHR 관찰 → 엔드포인트 학습) 추가 개발.
  기술 리스크가 아닌 '확인 작업'이므로 다음 세션 착수 가능.

## 4. 공지사항 8페이지 이후분

- **상태**: 해당 없음(소진 확인) — 9·10페이지 렌더 실측 결과 빈 페이지(602바이트 셸, 글 0건).
  공지사항 상세 **38건은 전수 수집 완료**. 단, 공지 글에 붙은 첨부파일은 1번 항목 사유로 미수집.

## 5. 외부 법령·예규 본문 (law.go.kr, 행정안전부 고시 등)

- **상태**: 본문 미수집 — 링크·앵커 텍스트만 저장(source_links, external_meta_only=true)
- **이유**: 실행 프롬프트 명시(외부 사이트 본문 수집 금지, 별도 allowlist 없이는)
- **영향**: 법령 원문 검색은 불가, 출처 안내는 가능
- **풀리는 조건**: 법제처 등 공공 API/allowlist 검토 후 확장

## 6. 이미지형 자료(카드뉴스·포스터 등)의 텍스트 내용

- **상태**: OCR 미수행
- **이유**: OCR은 최후 수단이며 현재 파이프라인은 이미지 형식 감지 시
  `MANUAL_REVIEW_REQUIRED` 격리 설계. 무단 재배포 우려도 있어(저작권) 보수적 처리.
- **영향**: 이미지 속 텍스트 검색 불가
- **풀리는 조건**: 저작권 확인 + OCR 워커(Python 보조) 도입

## 7. 로그인·인증 영역

- **상태**: 접근 시도 자체 없음(절대 원칙). 대상 사이트는 비로그인 공개 서비스라 현재 범위에
  필수 콘텐츠는 포함됨.
