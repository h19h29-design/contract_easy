## 4. 외부 법령 본문 (law.go.kr)

- **상태**: 코퍼스 raw HTML 전수 스캔 결과 law.go.kr 링크 **0건** → 수집 대상 부재로 종결.

  법령 내용 일부는 원문 페이지 본문/PDF 인용으로 이미 반영(예: 지방계약법 제27조, 행안부 한시적 특례).

## 5. 이미지/스캔 문서 OCR — ✅ 기술 검증 완료(2026-08-26)

- **결과**: pdf-parse getImage → tesseract.js(kor) 파이프라인 구현·동작 확인(191자 추출).
- **판정**: 대상 문서가 저화질 스캔이라 인식률 저조 → 자동 편입 대신 MANUAL_REVIEW_REQUIRED 격리 원칙 적용. 모듈은 유지(env INGEST_OCR=true 시 활성).
- **판정**: 대상이 극소수이므로 우선순위 낮음 — 필요 시 별도 세션에서 도입.
