# UNCOLLECTED.md — 수집하지 못한 정보와 그 이유

최종 갱신: 2026-08-26 (2차) — #2 FAQ는 **해결 완료**, 나머지는 아래와 같음.
무단 우회(robots·로그인·파라미터 추측)는 절대 원칙 위반이므로 수단으로 사용하지 않는다.

---

## 1. 첨부파일 원문 전체 (pdf / hwp / hwpx / doc / xls / xlsx / zip / png / jpg …)

- **상태**: 미수집 — 파일은 전부 **메타데이터만** 보관(URL·파일명·확장자)
- **이유**: `contract.sen.go.kr/robots.txt`가 해당 확장자 다운로드를 명시적 Disallow
  (2026-08-25 실측: `Disallow: /*.pdf$` 등 14종). seeds의 `obey_robots: true`와
  절대 원칙(robots 우회 금지)에 따라 차단. 결정 기록 D-001.
  ※ buseo.sen.go.kr robots도 동일하게 첨부 확장자 Disallow(2026-08-26 확인)
- **보유한 것**: 첨부 링크 목록(`data/manifests/files.jsonl`, sources.attachments)
- **영향**: 첨부 내부의 서식 양식·상세 표·안내문이 지식베이스에 없음 → 검색·위키 누락
- **풀리는 조건**: 서울시교육청 담당부서의 사전 서면 확인 후 `CRAWL_ALLOW_ATTACHMENTS=true`
  명시 승인 시 즉시 수집 가능(다운로더·MIME 검증·격리 로직은 구현·테스트 완료)

## 2. FAQ 게시판의 개별 Q&A 글 — ✅ 해결 완료(2026-08-26)

- **결과**: 외부 BBS(buseo.sen.go.kr)에서 **개별 Q&A 137건 수집 완료**
  - 원클릭 게시판(sn=1412): 32건 전체(4페이지 소진)
  - 기타 연관 게시판(1413~1417): 58+14+9+6+12 = 99건
    (부서업무방 공지·사전정보공표 성격 포함 — 오판 확장분 103건은 식별 후 삭제 정리함)
- **처리**: faq 타입 청크로 인덱싱(총 faq 청크 2,769개). 라벨: 시드 4종(inline) + FAQ-원클릭(외부 32건).
- **남은 한계**: 첨부파일은 1번 항목과 동일 사유로 메타만. 카테고리(general/goods/service/construction)
  필터는 외부 수집분에 적용되지 않음(게시판이 통합형이라 원문상 구분 없음).

## 3. 계약방법 '원클릭' 업종별 상세 표 (MI485~504 등 gb/gy 페이지군)

- **상태**: 미수집(빈 껍데기 확인됨)
- **이유**: HTTP·렌더 어느 쪽도 초기 응답에 본문이 없고, 콘텐츠를
  `fncSubView(gb, gy, gm, step, sort, index)` AJAX로 조립함. 유효 조합은 UI 클릭 탐색으로만
  학습 가능하며 **조합 추측은 금지**(추측 금지 원칙).
- **보유한 것**: 계약방법 핵심 표는 **사전체크리스트(용역/공사) 정적 페이지**에서 확보됨
  → 구조화 규칙 초안 3건(수의계약 2000만~1억 / 입찰 <1억 / 입찰 1억~2.3억) + 문장 후보(draft)
- **풀리는 조건**: Playwright UI-walk(탭 클릭 → XHR 관찰 → 엔드포인트 학습) 추가 개발.
  다음 세션 착수 예정(TASKS NEXT 1번).

## 4. 외부 법령 본문 (law.go.kr)

- **상태**: 수집 대상 링크 자체가 코퍼스에 0건(2026-08-26 raw HTML 전수 스캔) → 진행 불필요/보류
- **참고**: law.go.kr robots.txt는 Allow(/) — 향후 링크가 생기면 소량·정중 수집 가능.
  법령 내용 일부는 원문 페이지 본문 인용으로 이미 일부 반영되어 있음(예: 지방계약법 제27조 관련 문구).

## 5. 이미지형 자료(카드뉴스·포스터 등)의 텍스트 내용

- **상태**: OCR 미수행 — 그리고 **OCR 대상 파일 자체가 없음**(이미지 다운로드가 robots Disallow,
  1번 항목과 동일). 따라서 #5는 #1 해제가 선행 조건.
- **풀리는 조건**: #1 승인 후 tesseract.js(kor) 등 도입 검토
