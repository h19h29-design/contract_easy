## 제안하는 구현 범위

1. 첫 대상은 원본 `공사표준계약서`. 기존 로그인·프로젝트 소유권 검사를 재사용한다.
2. 공사·기관·업체 공통정보를 입력하고, 문서별 항목과 초안을 비공개 프로젝트에 저장한다.
3. 원본에서 확인한 항목을 채워 미리보기·수정·다운로드를 제공한다. 출력 형식은 사용자 확인 중이다.
4. 사용자가 입력한 계약금액·날짜와 법적 판단값을 구분한다. 기존 XLSM의 비율·기간 수식이나 고정값을 승인 없이 서비스 규칙으로 가져오지 않는다.
5. 검증은 입력 누락/날짜/금액 문자열 보존, 사용자 간 접근 차단, 초안 재조회, 원본 대비 필드와 출력 배치, 브라우저 작성→다운로드 흐름을 포함한다.

실제 서비스 구현은 아직 시작하지 않았다. 설계 스킬의 구현 전 확인 단계이며,
한글(HWP/HWPX) 필수 여부 또는 엑셀/PDF·DOCX/PDF 우선 여부를 질문했다.
원본 전체 배포·Git 추가, 매크로 실행, 운영 DB 변경은 하지 않는다.
